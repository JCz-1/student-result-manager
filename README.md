# Student Result Manager 

## About
The website/app allows seamless Management of Student results. Users can input student names and scores, 
automatically calculate grades, and view 
class statistics including average, highest, 
and lowest scores. 

## Features
This website/app has a form to input names and scores, a table to view list of all students. You can also edit student list by adding or removing. 
- Color coded grade cards — green for A, 
  blue for B, orange for C, red for F

## Technologies Used
HTML, CSS, Vanilla Javascript 

## How to Run
Quite Simple. Once it loads there's a form to fill: Name of Student and Score. A toggle button to view complete list of students.
